# [역할 정의]
너는 금융 데이터 시각화 및 대시보드 UI/UX 설계 전문가이다. 아래 가이드라인과 레이아웃 구조에 맞춰 국내 시장의 실시간 분위기를 모니터링할 수 있는 인터랙티브 대시보드를 React와 Tailwind CSS, 그리고 시각화 라이브러리(Recharts 또는 Chart.js)를 사용하여 구현해 줘.

# [레이아웃 구조]
1. 전체 화면은 상단의 '카테고리 네비게이션 바(Header)'와 하단의 '메인 대시보드 콘텐츠 영역'으로 구성된 수직적 구조로 설계한다.
2. 상단 헤더에는 서비스 로고와 함께 아래의 4가지 카테고리 메뉴를 가로로 배치한다.
   - 카테고리 1: 국내 전광판
   - 카테고리 2: 매크로 및 환율
   - 카테고리 3: 글로벌 연동
   - 카테고리 4: 국내 섹터 모멘텀
3. 메인 콘텐츠 영역은 전체 너비를 활용하여 지수 그래프를 그리드 레이아웃으로 배치한다.

# [컴포넌트 동작 및 상호작용 (Interaction)]
1. 사용자가 좌측 카테고리 중 하나를 클릭하면, 우측 메인 콘텐츠 영역에는 해당 카테고리에 속한 모든 지수의 그래프(Line Chart)가 한눈에 볼 수 있도록 그리드(Grid) 레이아웃으로 동적 렌더링되어야 한다.
2. 카테고리별 우측 메인 영역에 포함될 지수 리스트는 다음과 같다.
   - **[카테고리 1 클릭 시]**: 코스피 지수, 코스닥 지수, VKOSPI(공포지수), 외국인/기관 당일 순매수 대금 (총 4개 그래프)
   - **[카테고리 2 클릭 시]**: 원/달러 환율, 달러 인덱스, 미국 10년물 국채 금리, 한국 3년물 국고채 금리 (총 4개 그래프)
   - **[카테고리 3 클릭 시]**: S&P 500 / 나스닥 100 지수, 필라델피아 반도체 지수, WTI 원유 선물, 국제 구리 선물 (총 4개 그래프)
   - **[카테고리 4 클릭 시]**: KRX 반도체, KRX 2차전지, KRX 자동차, KRX 헬스케어, 코스피 200 중공업, KRX 인터넷, KRX 은행 (총 7개 그래프)

# [시각화 및 디자인 가이드]
1. 화면은 Grid 레이아웃(카테고리 1~3은 2x2 그리드, 카테고리 4는 3x2 또는 4x2 그리드)을 사용하여 모든 지수 그래프의 크기를 균등하게 배치하고, 스크롤을 최소화하여 '한눈에' 보이도록 한다.
2. 각 그래프 카드의 상단에는 지수 이름과 함께 현재가, 전일 대비 등락률(%)을 텍스트로 표시한다. (양수는 초록색/상승 화살표, 음수는 빨간색/하락 화살표로 시각적 차별화 필수)
3. 각 그래프의 변동 추이 결과는 실시간, 1일, 일주일, 1개월, 3개월, 1년 단위로 선택하여 볼 수 있게 한다.
4. 각 그래프에 커서를 올렸을 시 수치를 상세히 볼 수 있도록 한다.
5. 각 그래프 축에 수치 혹은 단위를 표현하여 숫자를 표시해주도록 한다.
6. 상단 네비게이션(Header)과 메인 대시보드 간의 경계(Border)를 없애고, 로고, 카테고리 탭, 그리고 섹션 제목 및 설명을 화면 중앙에 배치하여 전체적으로 수직적인 UI 흐름을 갖도록 구성한다.

# [타임프레임(시계열) 동적 처리 및 시각화 전략]
효율적인 데이터 렌더링과 정확한 시각화를 위해, 타임프레임 선택 시 다음과 같은 아키텍처 규칙을 따른다.

1. **데이터 소스 스위칭 (Network Routing)**
   - **실시간(Real-time)**: WebSocket(Socket.io)을 통해 1초 단위의 틱(Tick) 데이터를 지속적으로 스트리밍 받아 차트 우측에 덧붙인다(Append).
   - **과거 이력(1일~1년)**: WebSocket 구독을 즉시 해제(Unsubscribe)하고, REST API(`/api/v1/market/history`)를 호출하여 해당 기간의 완성된 시계열 배열을 한 번에 가져와 렌더링한다.

2. **백엔드 데이터 집계 (TimescaleDB Continuous Aggregates)**
   - 장기간의 차트를 그릴 때 수백만 개의 틱 데이터를 그대로 보내면 브라우저에 과부하가 발생하므로, 기간에 맞게 캔들(간격)을 리샘플링하여 제공한다.
   - **1일**: 5분 단위 집계 (약 60~70개 포인트)
   - **1주**: 4시간 단위 집계 (약 35개 포인트)
   - **1개월 / 3개월**: 1일 단위 집계 (약 30~90개 포인트)
   - **1년**: 1주일 단위 집계 (약 52개 포인트)

3. **프론트엔드 X축(시간) 포맷팅**
   - 차트의 X축은 사용자가 선택한 타임프레임의 '스케일(Scale)'에 맞춰 가장 가독성 높은 날짜/시간 포맷으로 자동 변형되어야 한다.
   - **실시간**: `HH:MM:SS` (예: 15:35:20)
   - **1일**: `HH:MM` (예: 15:30)
   - **1주 ~ 3개월**: `MM/DD` (예: 06/01)
   - **1년**: `YY/MM` (예: 26/06)
